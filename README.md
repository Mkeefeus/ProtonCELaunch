# ProtonCELaunch

ProtonCELaunch is a bash script to run Cheat Engine in a games proton prefix on Linux. To use: 
 1. make sure you have the Cheat Engine files somewhere on your system
 2. Gave run the game you want to attach Cheat Engine to at least once 
 3. Follow the scripts prompts.

## Notes
    - Currently supports Valves Proton and Proton GE, if you'd like support for other Proton versions please create a PR or open an issue.
